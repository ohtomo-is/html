ChatGPT で構成 → Claude で HTML 作成
GitHub 連携の手順

ChatGPT と相談して決めた構成を GitHub に渡すと、Claude が HTML を作ってプルリクエスト（PR）を出してくれます。

全体の流れ

ChatGPT会話で構成を決める
→
GitHub Issue「@claude 作って」と投稿
→
ClaudeHTML を作って PR を出す

① 準備（1回だけ）

  1. GitHub にリポジトリを作る

    例：my-pages。公開・非公開どちらでも OK です。

  2. Claude の GitHub アプリを入れる

    github.com/apps/claude を開き、作ったリポジトリにインストールします。

  3. API キーを登録する

    console.anthropic.com でキーを発行し、リポジトリの Settings → Secrets and variables → Actions に ANTHROPIC_API_KEY という名前で登録します。

  4. 設定ファイルを置く

    リポジトリに .github/workflows/claude.yml を作り、次の内容を入れます。

    name: Claude
on:
  issues:
    types: [opened]
  issue_comment:
    types: [created]
permissions:
  contents: write
  pull-requests: write
  issues: write
  id-token: write
jobs:
  claude:
    if: contains(github.event.issue.body, '@claude') || contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
💡 ターミナルで claude を起動し、/install-github-app を実行すると、手順 2〜4 をほぼ自動で設定できます。

② ChatGPT 側の渡し方

手軽

コピーして Issue に貼る

ChatGPT が出した構成をコピーし、GitHub で新しい Issue を作って貼ります。本文の先頭に @claude この構成でHTMLを作って と書けば動きます。

自動

カスタム GPT から直接投稿

GPT を作り、Actions に GitHub の「Issue 作成 API」を設定します。会話の最後に「Issue にして」と言うだけで投稿されます（GitHub のアクセストークンが必要です）。

③ 使うとき

  1. ChatGPT で構成を決める

    最後に決まった形式（目的・雰囲気・セクション一覧・素材）でまとめてもらいます。

  2. Issue を作る

    本文に @claude と構成を書いて投稿します。

  3. PR を確認して Merge する

    数分で Claude が PR を出します。中身を確認し、よければ Merge して完了です。

💡 まずは「手軽」な方法で動くことを確かめてから、「自動」に進むのがおすすめです。
